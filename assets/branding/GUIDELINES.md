# Branding Guidelines

## Logo & Design System

- Primary Color: #0066ff (Blue)
- Secondary Color: #1a1a2e (Dark Navy)
- Accent: #00d4ff (Cyan)
- Background: #ffffff (White) / #0a0a1a (Dark)

## Typography

- Headlines: Inter Bold/Semibold
- Body: Inter Regular
- Code: Fira Code

## Component Sizing

- Button: 48px height (min touch target)
- Card: 16px border radius
- Spacing: 8px base unit

See component library in `/components/` for implementation.
