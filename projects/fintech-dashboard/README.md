# Fintech Dashboard

Interactive financial dashboard UI component library.

## Features

- Real-time data visualization
- Chart integrations ready
- Portfolio overview
- Transaction history
- Alert system UI

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Quick Start

```bash
npm install
npm run dev
```
