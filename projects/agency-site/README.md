# Creative Agency Site

Portfolio website for creative and marketing agencies.

## Features

- Bold hero section
- Client showcase gallery
- Services grid
- Team profiles
- Case studies showcase

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Quick Start

```bash
npm install
npm run dev
```
