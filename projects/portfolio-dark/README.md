# Dark Portfolio

Professional portfolio with dark theme and modern design.

## Features

- Dark/light theme toggle
- Project showcase grid
- Smooth scroll animations
- Contact form
- Blog section ready

## Tech Stack

- React 18
- Vite  
- Tailwind CSS
- Framer Motion

## Quick Start

```bash
npm install
npm run dev
```
