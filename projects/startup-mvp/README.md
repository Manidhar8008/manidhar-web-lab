# Startup MVP

Minimal viable product showcase for early-stage startups.

## Features

- Clean, fast-loading interface
- Product demo section
- Early access signup
- Social sharing optimized
- Mobile-first design

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Quick Start

```bash
npm install
npm run dev
```
