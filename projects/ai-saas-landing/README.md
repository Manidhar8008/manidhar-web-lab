# AI SaaS Landing

A futuristic landing page for an AI-powered SaaS product.

## Features

- Modern hero with animated gradient background
- AI feature showcase with interactive demos
- Pricing comparison table
- Social proof and testimonials
- CTAs optimized for conversion

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Quick Start

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
