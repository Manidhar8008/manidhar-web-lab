## Adding a New Project

```bash
# 1. Copy template
cp -r templates/react-tailwind-template projects/my-new-site

# 2. Install dependencies
cd projects/my-new-site
npm install

# 3. Develop
npm run dev

# 4. Build & deploy
npm run build
```

Then add entry to this file.
